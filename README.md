# Dompet-Keluarga
Aplikasi web pengelolaan keuangan rumah tangga. Aplikasi ini dirancang untuk membantu keluarga memantau arus kas harian, mengatur batas anggaran bulanan (*budgeting*), mengelola target tabungan, mencatat portofolio investasi, serta mengekspor laporan keuangan dengan standar keamanan berlapis.
